## Como rodar o projeto ? 

- entre em Snippex_Frontend, com o comando *cd Snippex_Frontend/*
- rode o comando *npm install*
- logo em seguida rode o comando *npm run dev* para iniciar a aplicacao

- abra outro terminal e entre em Snippex_Backend, com o comando *cd Snippex_Backend/*
- rode o comando *npm install*
- logo em seguida rode o comando *npm start* para iniciar a aplicacao
